# 🧠 Deep Learning Experiment Project

A comprehensive web-based Deep Learning application that demonstrates multiple AI and Deep Learning models through an interactive user interface. This project is designed for students and researchers to explore different deep learning concepts in one place.

---

## 📌 Features

- 🔢 Handwritten Digit Recognition (ANN)
- 🐶🐱 Cat vs Dog Image Classification (CNN)
- 😀 Emotion Detection
- 💬 Sentiment Analysis
- 🌐 English to Hindi Translation
- ✍️ Next Word Prediction using LSTM
- 🤖 Text Generation using GPT-2
- 📝 Part-of-Speech (POS) Tagging
- 📊 Interactive Dashboard
- 🎨 Modern and Responsive UI

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/deep-learning-experiment.git
```

### Move into the Project Folder

```bash
cd deep-learning-experiment
```

### Create Virtual Environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Linux/Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000/
```

## 📖 Experiments Included

### 1. Handwritten Digit Recognition
- Uses an Artificial Neural Network (ANN)
- Predicts digits from uploaded images

### 2. Cat vs Dog Classification
- CNN-based image classification model
- Predicts whether the uploaded image is a cat or dog

### 3. Emotion Detection
- Detects human emotions from facial images

### 4. Sentiment Analysis
- Classifies text as Positive, Negative, or Neutral

### 5. English to Hindi Translation
- Neural Machine Translation model
- Converts English text into Hindi

### 6. Next Word Prediction
- LSTM model trained on text sequences
- Predicts the next probable word

### 7. GPT-2 Text Generation
- Generates meaningful text using GPT-2

### 8. POS Tagging
- Performs Part-of-Speech tagging for input sentences
